# RING CHAMPIONSHIP 웹사이트 (시안)

김내철 관장님께 보여드리기 위한 **예시(시안) 사이트**입니다.
빌드 도구나 설치가 필요 없는 순수 HTML/CSS/JavaScript로만 만들어져 있어,
폴더째 복사해서 전달하거나 그대로 웹서버에 올릴 수 있습니다.

---

## 1. 열어보는 방법

**방법 A. 로컬 서버로 열기 (권장)**

프로젝트 폴더에서 아래 명령을 실행한 뒤 브라우저에서 `http://localhost:5173` 접속.

```bash
python -m http.server 5173
```

**방법 B. 파일 직접 열기**

`index.html` 을 더블클릭해도 대부분 정상 동작합니다.
(브라우저 보안 정책에 따라 일부 이미지가 안 뜨면 방법 A를 사용하세요.)

## 2. 페이지 구성

| 파일 | 화면 | 내용 |
|---|---|---|
| `index.html` | 홈 | 히어로, 다음 대회, 최근 대회, FUTURE LEAGUE 배너, 지난 대회, 스폰서 |

| `future-league.html` | 아마추어 리그 | FUTURE LEAGUE 소개 + 참가 신청서 |

## 3. 내용 수정하는 법

### 대회 정보 — `assets/js/data.js` 한 파일만 고치면 됩니다

이 파일 안의 `EVENTS` 목록이 사이트 전체(홈·일정·상세)에 자동 반영됩니다.

- **새 대회 추가**: 목록 맨 위에 `{ ... }` 블록을 하나 복사해 붙여넣고 내용만 바꾸기
- **날짜**: `date: '2026-11-15'` 형식. 아직 안 정해졌으면 `date: ''` → 화면에 `No data` 로 표시
- **예정/지난 대회 분류**: 오늘 날짜 기준으로 **자동**입니다. (`status` 를 `'upcoming'` / `'past'` 로 적으면 강제 지정)
- **포스터**: 이미지를 `assets/img/` 에 넣고 `poster`, `thumb` 에 파일명을 적기
- **대회 등급**: `tier: 'PRO'` 는 RING CHAMPIONSHIP 본 대회(프로), `tier: 'AMATEUR'` 는 FUTURE LEAGUE 아마추어 대회.
  목록·상세 화면에 흰색 `PRO` / 초록색 `AMATEUR` 뱃지로 표시됩니다.

현재 `RING CHAMPIONSHIP 08` 은 **예시용 빈 카드**입니다.
실제 대회가 확정되면 날짜·장소·포스터를 채우고 `placeholder: true` 를 `false` 로 바꾸세요.

### 단체 정보 — 같은 파일 상단 `SITE`

유튜브·인스타그램 주소, 이메일, 전화번호는 지금 비어 있습니다.
값을 채우면 푸터에 링크로 표시되고, 비워두면 이름만 표시됩니다.

## 4. 아마추어 리그 신청서에 대해

지금은 **시안 동작**입니다. 입력 검증과 접수번호 발급, 접수 확인 화면까지는 실제로 동작하지만
데이터는 서버로 전송되지 않고 **접속한 브라우저에만 임시 저장**됩니다.
페이지 상단에도 데모임을 안내하는 띠가 표시됩니다.

실제 접수를 받으시려면 `assets/js/apply.js` 의 `submitApplication()` 함수 한 곳만 고치면 됩니다.
(구글폼 연동 / Formspree 같은 폼 서비스 / 자체 서버 중 선택)

## 5. 이미지에 대해

원본 이미지는 `images/` 폴더에 그대로 두었고,
웹에 쓰기 좋게 크기를 줄인 사본을 `assets/img/` 에 만들어 사용합니다.

- 포스터: `ring-02.jpg`, `ring-06.jpg`, `ring-07.jpg`, `fairtex-2024.jpg` (+ `-thumb` 목록용 축소본)
- 로고: `logo-ring-white.png` (검정 배경 화이트 로고), `logo-ring.png` (원본), `logo-future-league.png`
- 히어로 배경: `hero-bg.jpg`

## 5-1. 프로 / 아마추어 구분

`images/` 의 포스터 대회(RING CHAMPIONSHIP 02·06·07, FAIRTEX FIGHT 공동 개최)는 모두 **프로 대회**입니다.
프로 대회 페이지에는 아마추어 신청 버튼이 노출되지 않습니다.

## 5-2. 아직 비어 있는 내용 (확인 필요)

**확인되지 않은 내용은 지어내지 않고 비워두었습니다.** 아래 항목을 알려주시면 채워 넣겠습니다.

| 위치 | 필요한 내용 |
|---|---|
| `future-league.html` | 리그 이름, 리그 소개, 참가 자격, 접수 절차, 준비물 |
| `data.js` 의 `FL_SPORTS` | 실제 운영 종목 (비어 있으면 신청자가 직접 입력) |
| `data.js` 의 `FL_WEIGHTS` | 실제 체급 (비어 있으면 신청자가 직접 입력) |
| 신청서 개인정보 동의문 | 이용 목적 · 보유 기간 |
| `data.js` 의 `SITE` | 유튜브 · 인스타그램 주소, 이메일, 전화번호 |
| 대회 상세 페이지 | 티켓 구매처, 중계 링크 |

화면에는 값이 없는 자리가 전부 **`No data`** 로 표시됩니다.
`data.js` 에서 항목을 빈칸('')으로 두면 자동으로 `No data` 가 나오고, 값을 채우면 그대로 표시됩니다.

### FUTURE LEAGUE(퓨처리그)에 대해

`images/퓨처리그 로고.ai` 파일이 있고, RING CHAMPIONSHIP 07 포스터 **하단 스폰서 로고 줄**에
FUTURE LEAGUE 로고가 들어가 있습니다. 확인 가능한 사실은 여기까지입니다.

이 단체가 아마추어 리그인지, RING CHAMPIONSHIP 소속인지, 별개 파트너사인지는 확인되지 않아
사이트에서 아마추어 리그와 연결하지 않았습니다. 현재 FUTURE LEAGUE 는 **포스터에 나온 그대로
RING 07 의 스폰서 목록에만** 표시됩니다. 실제 관계를 알려주시면 그에 맞게 반영하겠습니다.
